# 知识卡片生成 Skill

## 核心工作流程

1. **接收输入**：获取用户提供的文章文本或本地文件路径（仅限 `.md`、`.txt`）
2. **内容分析**：通读全文，识别真正重要的知识点，忽略冗余、重复和次要信息
3. **提取知识点**：将核心知识拆分为 5～8 个独立知识点，每个知识点只讲一个概念
4. **生成卡片**：为每个知识点生成一张结构化知识卡片
5. **质量检查**：
   - 每张卡片是否只讲一个知识点？
   - 是否有重复内容？
   - 是否编造了原文没有的信息？
   - 信息不足时是否减少了卡片数量？
6. **输出结果**：以 Markdown 格式输出所有知识卡片

## 知识卡片格式

每张卡片必须包含以下四个部分：

```markdown
### 卡片 N：{标题}

**核心知识**：一句话概括该知识点的核心内容。

**简明解释**：用 2～4 句话解释该知识点，确保初学者也能理解。只使用原文中的信息。

**例子/自测问题**：提供一个具体例子帮助理解，或提出一个自测问题供用户检验掌握程度。
```

## 约束与准则

- **单点原则**：一张卡片只讲一个知识点，不要混杂多个概念
- **去重原则**：删除重复或高度相似的内容，合并到一张卡片中
- **忠实原则**：不能编造原文没有的信息，所有解释必须基于原文
- **数量原则**：优先生成 5～8 张；若原文信息不足，可减少到 3～5 张，不要强行凑数量
- **格式原则**：输出必须为 Markdown 格式，便于阅读

## 输入处理

### 直接粘贴文本
当用户直接粘贴文章时，直接分析文本内容。

### 本地文件
当用户提供文件路径时：
1. 验证文件扩展名是否为 `.md` 或 `.txt`
2. 读取文件内容
3. 若文件不存在或扩展名不支持，提示用户仅支持 Markdown 和 TXT 文件

## 不支持的功能

以下功能暂不支持，若用户请求，应礼貌说明：
- 网页抓取（URL 转知识卡片）
- PDF 文件处理
- Anki 卡片导出
- 图形界面（GUI）
