# make-knowledge-cards

将文章或本地文本文件转换为结构化知识卡片的 Skill。

## 功能

- 把用户粘贴的文章或本地 Markdown/TXT 文件转换成 5～8 张知识卡片
- 每张卡片包含：**标题**、**核心知识**、**简明解释**、**例子或自测问题**
- 提取真正重要的知识，删除重复内容，不编造原文没有的信息
- 信息不足时不强行凑数量

## 使用方法

### 方式一：直接粘贴文章

将文章内容直接发送给 Agent，Agent 会自动分析并生成知识卡片。

```
请把下面这篇文章转换成知识卡片：

[粘贴你的文章内容]
```

### 方式二：提供本地文件路径

提供本地 `.md` 或 `.txt` 文件的绝对路径，Agent 会读取文件内容并生成卡片。

```
请把 /path/to/你的笔记.md 转换成知识卡片
```

## 输入输出示例

### 输入示例

```
请把下面这段关于 TCP 三次握手的文章转换成知识卡片：

TCP（Transmission Control Protocol）是一种面向连接的、可靠的传输层协议。
在建立连接时，TCP 使用三次握手（Three-way Handshake）机制。
第一次握手：客户端向服务器发送 SYN 报文，请求建立连接。
第二次握手：服务器收到 SYN 后，回复 SYN+ACK 报文，表示同意建立连接。
第三次握手：客户端收到 SYN+ACK 后，回复 ACK 报文，连接正式建立。
三次握手的目的是确保双方的发送和接收能力都正常，防止历史重复连接初始化造成的问题。
```

### 输出示例

```markdown
### 卡片 1：TCP 协议概述

**核心知识**：TCP 是一种面向连接的、可靠的传输层协议。

**简明解释**：TCP（传输控制协议）工作在 OSI 模型的传输层。它在通信双方之间建立连接后才开始传输数据，并提供可靠性保障，确保数据不丢失、不重复、按序到达。

**自测问题**：TCP 和 UDP 最大的区别是什么？

---

### 卡片 2：三次握手的定义

**核心知识**：TCP 使用三次握手机制来建立连接。

**简明解释**：三次握手是 TCP 建立连接的标准流程，通过三个步骤完成客户端和服务器之间的连接初始化。这个过程确保双方都准备好进行数据传输。

**自测问题**：为什么 TCP 建立连接需要三次握手，而不是两次？

---

### 卡片 3：第一次握手（SYN）

**核心知识**：客户端向服务器发送 SYN 报文，请求建立连接。

**简明解释**：在三次握手的第一个阶段，客户端主动发起连接请求，向服务器发送一个 SYN（同步）报文。这个报文包含了客户端的初始序列号，用于后续的数据排序。

**例子**：就像你打电话给朋友，先说"喂，你在吗？"

---

### 卡片 4：第二次握手（SYN+ACK）

**核心知识**：服务器回复 SYN+ACK 报文，表示同意建立连接。

**简明解释**：服务器收到客户端的 SYN 后，如果同意建立连接，会回复一个 SYN+ACK 报文。其中 SYN 是服务器的同步信号，ACK 是对客户端 SYN 的确认。这表示服务器既能接收也能发送。

**例子**：朋友回复"在的，我也能说话，你能听到我吗？"

---

### 卡片 5：第三次握手（ACK）

**核心知识**：客户端回复 ACK 报文，连接正式建立。

**简明解释**：客户端收到服务器的 SYN+ACK 后，发送一个 ACK 报文作为最终确认。此时双方确认彼此的发送和接收能力都正常，连接建立完成，可以开始传输数据。

**例子**：你回复"能听到，我们开始聊吧！"

---

### 卡片 6：三次握手的目的

**核心知识**：三次握手确保双方的发送和接收能力都正常，防止历史重复连接初始化。

**简明解释**：三次握手的设计有两个关键目的：一是验证客户端和服务器双方的发送通道和接收通道都正常工作；二是防止因网络延迟导致的旧连接请求突然到达，从而错误地初始化一个已经失效的连接。

**自测问题**：如果只有两次握手，可能会出现什么问题？
```

## 限制

- 暂不支持网页抓取（URL）
- 暂不支持 PDF 文件
- 暂不支持 Anki 格式导出
- 暂不支持图形界面（GUI）

## 文件结构

```
skills/make-knowledge-cards/
├── SKILL.md              # Skill 定义和使用说明
└── agents/
    └── openai.yaml       # Agent 配置（系统提示、参数、输出格式）
```

## 工作原理

1. 用户粘贴文章或提供本地 `.md`/`.txt` 文件路径
2. Agent 分析文本，提取核心知识点（5～8 个）
3. 每个知识点生成一张结构化卡片
4. 以 Markdown 格式输出，便于阅读和进一步编辑
